# ConnectWorld

A modern global social networking interface for meeting new friends around the world.

## Current build
- Responsive Facebook/Instagram-inspired blue and white interface
- Global feed with text/image posts
- Discover people by country and interests
- Friend suggestions
- Friends, messages and notifications sections
- Login/sign-up modal UI
- GitHub Pages compatible static frontend

## Planned production integrations
The production version can connect the UI to Supabase for:
- Email/password authentication
- Password reset
- User profiles and profile pictures
- Posts, likes, comments and shares
- Friend requests and friendships
- Real-time one-to-one messaging
- Online/offline presence
- Notifications
- Image storage

### Supabase configuration
Do not commit private Supabase service-role keys. Browser clients should only use the Supabase project URL and publishable/anon key.

## Publish
This repository can be published with GitHub Pages from the `main` branch using the repository root as the source.
